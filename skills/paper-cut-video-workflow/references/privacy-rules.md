# Privacy Rules

- Do not include private reference voice, private video, raw product documents, API keys, or consent files in the skill folder.
- Store sensitive material only in the active project folder.
- Do not upload private material to external services unless the user explicitly asks and the tool/service is appropriate.
- Keep a note of voice authorization when voice cloning or reference voice generation is used.
- For public-figure or third-party voices, require explicit authorization; otherwise use a neutral synthetic or human-recorded alternative.
