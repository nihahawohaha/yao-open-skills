# Script And Storyboard Template

Create a compact script first, then expand to a shot list.

## Structure

1. Hook: visual or spoken opening in the first 1-3 seconds.
2. Problem: one concrete pain point.
3. Reveal: product, method, or transformation.
4. Proof: feature, result, scene, testimonial, or sensory detail.
5. CTA: simple action with enough breathing room.

## Output Format

```text
Title:
Duration:
Platform:
Audience:
Core promise:

Narration:
1.
2.
3.

Screen text:
1.
2.
3.

Shot list:
| Shot | Time | Narration | Visual | Layers | Motion | Text | SFX | Notes |
|---|---:|---|---|---|---|---|---|---|
```

## Writing Rules

- Prefer short spoken lines that can be read aloud naturally.
- Keep one idea per shot.
- Use concrete verbs: unfold, slide, reveal, stack, bloom, lift, stamp.
- Avoid vague claims unless the user provides proof.
- Mark any uncertain product claim as `needs confirmation`.
